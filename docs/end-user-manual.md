# End User Manual

## Account

Register with an email and password, then sign in. The account dashboard shows
subscription status, session balance, next and upcoming bookings, payment and
receipt history, notifications, and profile details.

## Booking

Open **Book a Class** to view available, booked, and unavailable slots. Booked
slots remain visible. If a requested slot is taken concurrently, the system
may suggest the next available slot; accepting the suggestion creates the
booking, while cancelling creates nothing.

## Changes and payments

Members can cancel a booking or submit a reschedule request. Admin transfers
and reschedules require approval and never move a booking immediately.
Subscription and single-slot payments create a receipt and remain available in
payment history for download.

## Notifications and profile

Use the notification bell to read booking, transfer, subscription, and payment
updates. Update name and phone number from **My Profile**.
