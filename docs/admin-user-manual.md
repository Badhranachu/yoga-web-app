# Admin User Manual

## Sign in

Open the application, sign in with an admin account, and use the dashboard
sidebar. Admin permissions are enforced by the API as well as the route guard.

## Dashboard

The Overview page shows bookings, revenue, users, subscriptions, slots,
transfer requests, leaves, recent payments, recent bookings, and trends.

## Studio operations

- **Classes:** edit weekly timetable hours, slot duration, generation horizon,
  and future leave periods.
- **Bookings:** review all reservations, mark attendance, revert attendance,
  request transfers, and approve or reject user reschedules.
- **Payments:** review revenue, configure subscription and single-slot prices,
  and download receipts.
- **Reports:** select a history report, search/filter/sort it, page through
  records, or export the filtered result as CSV/PDF.

Attendance is the event that deducts a subscription session. Reverting
attendance restores the session tied to that booking.
